# DB ダンジョン

データベースの内部構造をダンジョンとして降りていく、ブラウザの RPG です。
SQL がパーサー → 意味解析 → オプティマイザ → 実行 → ストレージと処理される順番を、そのまま階層にしています。
遊んでいるうちに「DB の中で SQL がどう扱われているか」がわかることを目指しています。

いま遊べるのは **B1 パーサー階の Lv1** だけです（試作）。

## 遊び方

- 敵は「お題」を出してきます（例：users 表の中身を全部見せろ）
- お題に合う SQL を **呪文として自分で打って** 唱えます（Tab で補完、Ctrl+Enter で唱える）
- 本物の SQL パーサー（[node-sql-parser](https://github.com/taozhi8833998/node-sql-parser)、SQLite 方言）が呪文を構文木にします
- お題が求める構文木の部品と照合し、1 回の呪文で全部の部品がそろえば敵を倒せます
- 文法を間違えると、パーサーが実際に読めなくなった位置で呪文が途切れ、反動を受けます
- 画面下の「解析の書」で、字句解析・構文木・照合の結果を見返せます

## 大事にしていること

**本物の DB とずれないこと。** たとえば 1 面はパーサーの階なので、勝ち負けは「構文木の形」だけで決めます。
存在しない表名もパーサーは通します（表があるかを確かめるのは次の意味解析の仕事です）。ゲームでもそのとおりに振る舞います。
レベルを上げても攻撃力は増えません。強くなる＝書ける文法が増える、です。

## 動かし方

```sh
npm install
npm run dev      # http://localhost:5173/
npm test         # ユニットテスト
npm run build    # 型チェック＋ビルド
```
